"Suicide triggers" have been replaced with "expire triggers". The `!` syntax will continue to work, but now tasks will be marked as "expired" rather than just being removed from the workflow.

This is breaking change in the niche situation where a "completion expression" has been manually specified for a "suicide-triggered" task - in which case `or expired` should be added to the end of the expression

The `cylc graph --show-suicide` option has been renamed to `cylc graph --show-expire`.
